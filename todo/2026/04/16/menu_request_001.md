1. 메뉴 버튼을 클릭하면 util 버튼(챗봇, 최상단이동, 홈 등등)을 제외한 모든 영역을 block 처리.
 - modal처럼 backdrop으로 가려서 다른 화면 조작하지 못하게 하기
 - backdrop 영역을 클릭하면 메뉴가 닫히고 다시 화면 조작 가능하도록 처리
 - 스크롤 이동으로 인해 헤더가 사라진 상태에서 메뉴 버튼 클릭 시 무조건 활성화하고, backdrop을 클릭해서 메뉴가 닫히면 스크롤 위치에 따라 헤더 활성화/비활성화
 - 메뉴가 열려있는 상태에서 util 버튼(챗봇, 최상단이동, 홈 등등)을 클릭하면 메뉴가 다시 닫히고 클릭한 버튼의 기능 동작

2. 메뉴 클릭 시 메뉴 리스트를 닫고 스크롤은 항상 최상위로 이동
 - 해당 메뉴로 화면이 바뀔 때, 메뉴는 항상 닫히고 스크롤을 항상 최상위로 이동시킴

3. 디자인
 - 메뉴 리스트의 배경색은 없음
 - 메뉴 하나당 아이콘 | 메뉴 이름 으로 출력
 - 아이콘 : 원형, 배경색 흰색
 - 메뉴 이름 : 텍스트 뒷 배경 흰색, 메뉴 이름 영역 전체 칸은 배경색 없음
 - mouse-over : 글자/아이콘 색과 배경색 reverse
