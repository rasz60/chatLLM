## 4. 주식 검색 API 버그 수정 (오후)

### 증상
`005930`(삼성전자) 검색 시 `"조회된 데이터가 없습니다.(해외주식기본)"` 오류.

### 원인
`Search` 핸들러가 `search-stock-info` 엔드포인트에 가격조회용 TR_ID(`FHKST01010100`)를 잘못 사용.  
KIS 서버가 해외주식 서비스로 라우팅하여 국내 종목 데이터를 찾지 못함.

### 최종 수정: `backend/handlers/stock.go`

| 구분 | 변경 전 | 변경 후 |
|------|---------|---------|
| Search 엔드포인트 | `search-stock-info?PRDT_TYPE_CD=300&PDNO=` + `CTPF1702R` | `inquire-price?FID_COND_MRKT_DIV_CODE=J&FID_INPUT_ISCD=` + `FHKST01010100` |
| Search 응답 파싱 | KIS 원본 JSON 그대로 전달 | `hts_kor_isnm` 추출 후 `{output:{pdno, prdt_name}}` 형태로 가공하여 반환 |
| Price TR_ID | `FHKST01010100` | `FHKST01010100` (변경 없음, 원래 정상) |

`search-stock-info` + `CTPF1702R` 조합을 시도했으나 여전히 실패하여, 이미 동작이 검증된 `inquire-price` 엔드포인트를 재활용하는 방식으로 확정.  
`hts_kor_isnm` 필드에 한글 종목명이 포함되어 있어 검색 결과로 활용 가능.

## 최종 App.tsx 구조

```
App()
  ├── state: isScrolled, showMenu, currentPage
  ├── closeMenu() — setShowMenu(false)
  ├── navigate(page) — currentPage 변경 + closeMenu + 스크롤 상단 이동
  ├── handleMenuItemClick(item) — navigate / link scroll / newWindow
  ├── <header> — isScrolled && !showMenu 일 때만 hidden
  │     └── [menu-btn] [logo] [StockBanner]
  ├── {showMenu} → <menu-backdrop onClick=closeMenu> + <menu-dropdown>
  ├── <main> — WorkReport / SalaryReport / ChatWidget 페이지 전환
  ├── {isScrolled} → floating buttons (z-index 1060, backdrop 위)
  └── <ChatWidget />
```
