# 2026-05-22 작업 내역

## 개요
주식 검색 기능 확장: 국내/해외 종목을 코드·이름으로 모두 조회할 수 있도록 전면 재작업.
KRX API (서버 차단) → NAVER 증권 API (서버 차단) → Yahoo Finance API 로 최종 전환.

---

## 1. 국내 주식 검색 API 전환

### 배경 및 문제점

| 시도 | 결과 |
|------|------|
| KRX API (`data.krx.co.kr`) | Cloudflare 봇 보호로 서버 요청 차단, 15초 타임아웃 후 응답 없음 |
| NAVER 증권 API (`m.stock.naver.com/api/search/integration`) | HTML 에러 페이지 반환 (봇 보호) |
| **Yahoo Finance** (`query2.finance.yahoo.com/v1/finance/search`) | **정상 작동** ✓ |

### Yahoo Finance 검색 결과 구조

```
005930 검색 → 005930.KS (exchange: KSC) → SamsungElec → KOSPI
```

- `KSC` = KOSPI, `KOE` = KOSDAQ
- 심볼에서 `.KS` / `.KQ` suffix를 제거하면 6자리 코드 획득
- 6자리 코드로 직접 검색해도 `.KS` 종목이 우선 반환됨

## 2. 수정 파일: `backend/handlers/stock.go`

### 주요 변경 사항

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| 국내 검색 함수 | `searchKRX` → `searchNaver` (모두 차단됨) | `searchDomestic` (Yahoo Finance 기반) |
| 거래소 매핑 | 없음 | `yahooKorExch` map: KSC→KOSPI, KOE→KOSDAQ |
| 해외 검색 (`searchOverseasByName`) | 알 수 없는 거래소 코드 그대로 사용 | 알 수 없는 거래소 skip, 한국 거래소(KSC/KOE) 별도 처리 |
| KOSDAQ 가격 조회 | `FID_COND_MRKT_DIV_CODE=J` 하드코딩 | market이 KOSDAQ이면 `Q`, 나머지는 `J` |

### 검색 흐름

```
detectQueryType(query)
  ├── "domestic_code"  (6자리 숫자)  → searchDomestic(query, exactCode=true)
  ├── "domestic_name"  (한글 포함)   → searchDomestic(query, exactCode=false)
  └── "overseas"       (그 외)       → searchOverseas(query)
                                          ├── isLikelyTicker → KIS 코드 직접 조회
                                          └── searchOverseasByName → Yahoo Finance
                                               (KSC/KOE 종목도 함께 반환)
```

### 지원 검색 케이스

| 검색어 | 타입 | 결과 |
|--------|------|------|
| `005930` | domestic_code | 삼성전자 (KOSPI) |
| `AAPL` | overseas → KIS 직접 | Apple (overseas:NAS) |
| `Samsung` | overseas → Yahoo | 005930 SamsungElec(KOSPI) 포함 다수 |
| `Apple` | overseas → Yahoo | AAPL (overseas:NAS) |
| `삼성전자` | domestic_name | Yahoo 한글 미지원 → 빈 결과 (제한사항) |

### 제한사항
- **한글 이름 검색** 불가: Yahoo Finance는 한글 입력 쿼리를 지원하지 않음.  
  → 종목코드(6자리) 또는 영문명으로 검색할 것.

## 최종 stock.go 구조

```
StockHandler
  ├── getToken()                  — KIS OAuth2 토큰 (캐시)
  ├── kisGet(path, trID)          — KIS API GET 공통
  ├── checkConfig()               — API 키 유효성 확인
  ├── detectQueryType(q)          — 검색어 분류 (domestic_code/name/overseas)
  ├── yahooKorExch                — KSC→KOSPI, KOE→KOSDAQ
  ├── searchDomestic(q, exact)    — Yahoo Finance, 한국 거래소 필터링
  ├── kisExchanges                — NAS/NYS/AMS/TSE/HKS/SHS/SZS
  ├── searchOverseasByCode(code)  — KIS exchanges 순회하며 코드 조회
  ├── yahooToKIS                  — Yahoo 거래소코드 → KIS 거래소코드
  ├── searchOverseasByName(q)     — Yahoo Finance (KSC/KOE 포함 전체)
  ├── isLikelyTicker(s)           — 1~6자 영숫자 → 티커로 판단
  ├── searchOverseas(q)           — 티커면 KIS, 아니면 Yahoo
  ├── Search (POST /api/stock/search)  — 검색 핸들러
  └── Price (POST /api/stock/price)    — 가격 핸들러 (KOSDAQ Q 지원)
```
